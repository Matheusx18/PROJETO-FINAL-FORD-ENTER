# Baba dos Campeões - Plataforma de Gestão

## Sobre o Projeto
O "Baba dos Campeões" é uma aplicação web desenvolvida como Desafio Final. Trata-se de um sistema de gestão para campeonatos de futebol amador, focado em administrar jogadores, finanças (mensalidades), estatísticas de partidas e criação equilibrada de equipas.

## Tecnologias Utilizadas
* **Front-end:** Angular, TypeScript, HTML5, CSS3, JavaScript.
* **Versionamento e Deploy:** Git, GitHub e GitHub Pages/Vercel.

## Evolução e Principais Funcionalidades
A aplicação foi construída iterativamente, aplicando conceitos chave da formação:
* **Matemática e Lógica:** Implementação de algoritmos para o cálculo dinâmico da nota de cada jogador (baseado em golos, assistências e cartões) e sistema de sorteio para dividir equipas de forma justa.
* **Requisitos Legais (LGPD):** Integração de um ecrã de Termos de Privacidade, exigindo o consentimento explícito do utilizador antes do acesso.
* **Segurança de Acesso:** Criação de um sistema robusto de geração de chaves únicas para os Administradores, garantindo que o login exige validação estrita de e-mail e código gerado pelo sistema.
* **Design e UI:** Criação de uma interface responsiva, no formato SaaS, com navegação intuitiva através de uma sidebar retrátil.
